# فيديو «لا تعلّق مهتم… تواصل» — المصدر

## المعاينة
افتح `index.html` في Chrome أو Edge: يشتغل الفيديو مع شريط تحكّم.
- **مسافة:** تشغيل / إيقاف.
- **← →:** إطار للخلف / للأمام.
- **الشريط:** للانتقال إلى أي لحظة، والوقت بالثواني يظهر بجانبه (مفيد لضبط التوقيتات).

## أين تعدّل
كل شيء في `index.html`، والمشاهد مفصولة بعناوين مثل `// ═══ Step 1 — the message`.

- **النصوص:** ابحث عن النص نفسه بالعربية وغيّره.
  - في `headline("…", {…})` الرمز ` | ` يكسر السطر.
  - `hl: [...]` الكلمات الخضراء، و`red: [...]` الكلمات الحمراء. اكتب الكلمة كما هي في النص، مع علامات الترقيم.
- **التوقيت:** `start` و`end`، أو `a` و`b`، بالثواني.
- **الموضع والحجم:**
  - `y` و`x` بالبكسل داخل إطار 1080×1920.
  - `size` حجم الخط.
- **نص الرسالة:** مصفوفة `BODY`، وكل سطر معه العلامة التي تظهر بجانبه.
- **الألوان:** في `<style>` أعلى الملف، الأخضر `#2ee6a0` و`#00a355`.
- **مدة الفيديو:** `window.DURATION`.

## التصدير إلى MP4
يحتاج Node.js و ffmpeg و Playwright (`npm i playwright && npx playwright install chromium`):
```bash
node capture.cjs "$PWD" video sanad-apply-reel.mp4
```
للقطات ثابتة: `node capture.cjs "$PWD" stills ./out 3.5 12 30` (الأرقام بالثواني).

## الصوت
`sfx-cues.json` جدول المؤثرات: لكل مؤثر وقته (`sync`)، ومستواه (`gain` بالديسيبل)، ووصفه.
بعد تغيير التوقيت، عدّل الأوقات هنا ثم ابنِ المسار بأداة مكتبتك `motion-studio`:
```bash
python3 <motion-studio>/tools/audio/sfx-pipeline/build_track.py sfx-cues.json out --video sanad-apply-reel.mp4 --mix
```
الناتج `out/preview.mp4` هو الفيديو مع الصوت.
